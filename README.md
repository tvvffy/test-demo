# 教辅工作管理

一个给教辅部门管理者用的轻量网页工具，聚焦三件事：

- **任务与排班安排**：给教辅人员安排具体任务（晚辅、组卷校对、作业批改、磨课……），标注排期和截止时间。
- **工作完成情况统计**：一眼看到总体完成率、逾期任务、每位教辅的工作量和完成情况、各类型任务的完成占比。
- **绩效考核**：按《绩效考核表》平时记扣分、月底录分数，自动算出每人各项得分、总分和排名，导出 Excel 签字存档。

## 运行

需要 Node.js（建议 18+）。

```bash
npm install
npm start
```

然后打开 <http://localhost:3000> 即可使用。

开发时可以用 `npm run dev`（文件变化自动重启）。

## 数据存储

数据保存在本地 SQLite 文件 `data/jiaofu.db` 中（首次启动自动创建），不会随代码提交到仓库。这是单机单用户工具，建议定期备份这个文件；换电脑运行时把它拷过去即可保留全部数据。

## 功能说明

- **仪表盘**：总任务数 / 完成率 / 进行中 / 已逾期 的统计卡片；按教辅人员的完成率对比；需要关注的逾期任务列表；按任务类型的完成情况。
- **任务与排班**：新建 / 编辑 / 删除任务，指定负责人、排期日期、截止日期、状态和备注；按人员、按状态筛选；一键标记完成。「已逾期」由截止日期自动判定，不需要手动维护。
- **教辅人员**（右上角 👥）：维护教辅人员名单，供任务分配和绩效考核使用。删除某位人员时，其名下任务会变为「未分配」，不会被一并删除；其绩效考核记录会一并删除（已归档月份的结果不受影响）。

### 绩效考核

首次启动时，考核项按《绩效考核表（9月份暂行）》自动写入（7 项，满分 100）。之后要调整分值、扣分标准、及格线，在「绩效考核 → 考核规则」里改即可。

每个考核项的得分 = 基础分 − 扣分，最低 0 分。基础分按计分方式确定：

| 计分方式 | 基础分 | 表里对应的项目 |
|---|---|---|
| 扣分制 | 满分 | 资料完成度、带班讲课完成度、跟进学员 |
| 比例制 | 本月录入分数（百分制）的平均分；低于及格线记 0，否则 平均分 ÷ 100 × 分值 | 学员满意度（70）、月度能力测评（80）、磨课完成（85） |
| 直接打分 | 本月录入分数的平均分（0~分值） | 其他工作响应 |

扣分 = Σ 扣分规则分值 × 数量。例：磨课 3 次平均 90 分、缺 1 次 → 90 ÷ 100 × 15 − 5 = 8.5 分。

- **平时**：遇到要扣分的事点「+ 记扣分」（谁、哪天、哪一条、数量、备注）。按周核对的项目（如每天沟通 3 人）可以填「应完成 / 实际完成」，自动算出缺少的数量。
- **月底**：用「+ 录入得分」填满意度、能力测评分数；磨课每次录一条，按平均分算。比例制和直接打分的项目本月没有录分时显示「未录入」，按 0 分计入总分。
- **结果**：每人各项得分、总分、排名；点姓名看每一分扣在哪里。「近 6 个月总分」可以看每个人的变化。
- **导出 Excel**：第一页汇总，之后每人一页，版式沿用考核表，带得分说明和考核人 / 被考核人 / 人力资源签字栏。
- **归档**：月底定稿后点「归档本月」，结果就锁定了：不能再增删该月记录，之后改规则也不影响该月。需要修改时可以取消归档，取消后按当前规则重新计算。

## 目录结构

```
server/          Express 后端（REST API + SQLite）
  ├── db.js              数据库连接、建表、默认考核项
  ├── lib/status.js      任务状态与逾期判定的共用逻辑
  ├── lib/kpi.js         绩效计分逻辑（月度结果、归档快照）
  ├── lib/kpiExport.js   绩效考核 Excel 导出
  └── routes/             /api/staff  /api/tasks  /api/stats  /api/kpi
public/          纯前端静态页面（无需构建，原生 HTML/CSS/JS）
```

## 后续可以加的方向

视需要可以再加：教辅人员档案（联系方式、负责科目）、学员分配与工作量视图、逾期的资料类任务一键转为扣分记录、教辅自己填日报（需要部署成多人使用）等。
